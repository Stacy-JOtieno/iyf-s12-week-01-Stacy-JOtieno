## Website 2
#### Tag

#### How is the search bar structured?
<mdn-search-modal id="mdn-search"> - it is the custom component that warps the search interface
#shadow-root - contains the component's internal HTML structure and styles
<dialog> - provides the search modal window
<form method="get" action="/en-US/search">...</form> - groups the search controls and submits the search query to MDN's search page
<div role="status"> - provides status messages for assistive technologies
<mdn-button class="close"> - provides a button to close the search modal

#### What happens when you hover over links (check the styles)?
When you hover over the links the underline disappears. It is because the Css has :hover pseudo-class and the text-decoration: none
