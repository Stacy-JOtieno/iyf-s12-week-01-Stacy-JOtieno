## Project Description
This project is part of my web development learning journey, where I explored the foundations of building websites using HTML5 and CSS3.

Throughout Week 1, I worked on different practical exercises to understand webpage structure, semantic HTML, accessibility, navigation, contact information, image galleries, and blog layouts.

The main objective was to develop a strong foundation in web development by creating independent webpages and practising different HTML elements and CSS styling techniques.

## Technologies Used
- HTML5
- CSS3
- Git and GitHub
- Visual Studio Code
- Live Server Extension

## Features
The project contains several independent exercises completed throughout the week:
1. Personal Portfolio Website: Created a personal webpage introducing myself, my interests, skills, and aspirations.
2. Semantic HTML: Used semantic elements such as <header>, <main>, <section>, and <footer> to improve webpage structure.
3. HTML Elements Exploration: Explored additional HTML tags, including <abbr>, <blockquote>, <cite>, <code>, <mark>, <time>, <details>, and <summary>.
4. Navigation Menu: Created a navigation bar with a website logo and four navigation links using the <nav> element.
5. Contact Section: Practised using the <address> tag, email links (mailto:), telephone links (tel:), and social media links.
6. Photo Gallery: Created a six-image gallery using CSS Grid, <figure>, and <figcaption>.
7. Blog Post Layout: Designed a blog article containing a title, author information, publication date, featured image, subheadings, paragraphs, and related posts.
8. Accessibility Improvements: Improved image alternative text, heading hierarchy, descriptive links, and semantic structure.
